# User Stories: Language + Style Setting (Non-Developer Install)

---

## Reading Proposals

**As a German non-developer user**, I want proposal titles, change lines, and detail fields in plain German, so that I can understand what is being suggested without translating or decoding developer terms.

**As a German non-developer user**, I want evidence notes phrased as everyday explanations of what happened in my sessions, so that I can judge a proposal without knowing how the mining engine works.

**As a German non-developer user**, I want engine terms (worktree, gate, transcript mining, consolidation) never to appear in what I read, so that the system feels like a helpful assistant rather than a developer tool.

---

## Using the UI

**As a German non-developer user**, I want the navigation, page headings, and welcome/tutorial in German, so that the first thing I open already speaks my language.

**As a German non-developer user**, I want to see only the pages relevant to me (overview, proposals, sessions), so that I am not confronted with internals like skills, context packs, or repo management.

**As a German non-developer user**, I want proposal cards without gate bands, tags, and target paths, so that a card shows only what it suggests and why.

---

## Trust / Consistency

**As a German non-developer user**, I want nightly runs to keep everything German and jargon-free, so that no English developer prose leaks in over time.

**As a German non-developer user**, I want technical code blocks visibly marked as technical detail and left untranslated, so that I know what to skip and nothing is garbled by translation.

---

## Operator

**As the operator (Kevin)**, I want to set the presentation profile once at install, so that the machine is fully configured for its user without ongoing manual styling.

**As the operator (Kevin)**, I want to switch a machine back to developer/English mode, so that I get the full UI and register when I maintain it.

**As the operator (Kevin)**, I want repo content, logs, and pipeline results to stay English regardless of the profile, so that my operator workflow and cross-machine tooling are unaffected.
