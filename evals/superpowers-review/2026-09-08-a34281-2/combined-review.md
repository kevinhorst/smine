## Issues

### Critical

1. **ACDSL policy gate is bypassable through base-ref resolution** — internal/acdsl/policy.go (golden GV3-001, 12/34 arms; GV3-002, 6/34; GV4-202, 1/34; plus the unresolvable-base sibling found by 5/34 — re-verification ruled it a variant of golden GV3-108, not uncataloged: the early-out consults the untrusted working-tree policy's `Mode`, so deleting or editing policy.json in a gated/strict repo disables the whole self-management gate). Working `base_ref` resolving to a pre-policy base short-circuits into free mode; `base_ref` naming a branch makes `isBoundary` false and `CheckPolicy` returns nil before any diff; `policyBase()` never checks the resolved merge-base against HEAD. This family is the single most-confirmed defect cluster in the range.
2. **install.sh embeds unsanitized env values into the launchd plist** — install.sh (GV3-167, 1/34). PEEK_CLAUDE_HOME / PEEK_CODEX_HOME are substituted raw (no XML escaping) into `PEEK_HOME_ARGS`.
3. **Nightly orchestrate jq-merges the git-ignored repos.json into global settings** — routines/smine-nightly/run.sh (GV3-196, 1/34). Every path in the untracked repo-root registry lands in the user's global settings unconditionally.
4. **acdsl-policy-guard.sh unconditionally denies writes to acdsl/registry.local.json** — cmd/hooks/acdsl-policy-guard.sh (uncataloged, 3/34, claimed up to Critical). The fast hook denies in gated/strict mode what the authoritative check deliberately permits (local_overrides escape hatch / exclusion of the local overlay), so the documented override path is dead when reached via Write/Edit.

### Important

5. **skill-invoke-gate.sh recognizes only two read shapes** — cmd/hooks/skill-invoke-gate.sh (GV3-166, 15/34 — the most-found issue overall). Post-invocation, governed-context reads made through any tool other than the two matched shapes satisfy nothing / escape the gate.
6. **skill-invoke-gate.sh prefix matches are unanchored** — cmd/hooks/skill-invoke-gate.sh (uncataloged, 3/34). `"/$required"*` lets `/smine-batch` satisfy required `smine`, and the prompt-start slash match accepts `/railroad-review-observability` for `railroad-review`. A sibling arm (1/34) also showed the hook skips enforcement entirely for any Bash command containing a quote.
7. **Global settings template drops the acdsl Edit/Write allowlist entries** — settings/claude_code/settings.json (GV3-198, 8/34). `Edit/Write(**/*.acdsl, acdsl/**)` removed from the template.
8. **smine-orchestrate frontmatter grants unrestricted `Bash(git *)`** — skills/smine/smine-orchestrate/SKILL.md (GV3-137, 1/34).
9. **The casual-audience skill-edit lockout is prose-only** — skills/smine/smine-apply, smine-skills, smine-orchestrate SKILL.md (3/34; re-verification: matches golden GV5-237, so cataloged, not new). The plan's hard gate (DR3 / "never propose edits to skills the user doesn't own") has no hook or code enforcement anywhere in the range.
11. **handleRepoWorktreeStatus serves stale state when a fresh scan fails** — internal/server/repos.go (uncataloged, 3/34). After a fingerprint mismatch or `?refresh=1`, a failed `repos.Status` leaves `entry` at the stale cache value while `ScannedAt` is stamped unconditionally — the page shows an error banner over silently stale data with a fresh timestamp.
12. **config_sync peek-multiple-profiles plan drift** — internal/server/config_sync.go (GV3-135, 1/34) and **profile-test plan deviations without Changelog entries** — internal/server/profilesettings.go (uncataloged, 2/34): styleTestPrompt and handleProfileTest diverge from the smine-profile-settings plan's D8/D9 with no recorded post-approval adjustment.
13. **Stage runners fail open when routine_allowed_tools errors** — cmd/bootstrap/run.sh + routines/smine-nightly/run.sh (uncataloged, 1/34).
14. **Orchestrate merge runs on the real main checkout** — routines/smine-nightly/run.sh + cmd/bootstrap/run.sh call sites (uncataloged, 1/34), and the additionalDirectories reconciliation mutates the user's global ~/.claude/settings.json unconditionally whenever orchestrate=1 (uncataloged, 1/34).

## Assessment

**Ready to merge? With fixes.** The pooled arms confirm one Critical cluster that must land before anything else: the ACDSL policy gate's base-ref bypass family (issue 1) plus its enforcement-hook contradictions (issues 4–6). The install.sh plist injection (2) and the nightly settings merge (3) are one-line-class fixes with real blast radius. Everything else is Important-or-below hardening and plan-drift reconciliation.

**Coverage caveat:** this is a union of 34 shallow single-pass reviews, not a full review — pooled, they still miss 89.3% of the human-confirmed golden (225 of 252 findings, 86.2% by weight). The union is dominated by loud, high-signal defects; treat absence from this document as no evidence of absence.
