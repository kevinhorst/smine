Agent Skills standard

AspectFinding
The standardOpen, at agentskills.io (Anthropic, Dec 2025): a folder plus SKILL.md with two required YAML fields (name, description) and a prose body. Optional: license, compatibility, metadata; allowed-tools is experimental. Spec repo agentskills/agentskills: ~40 open issues, no published roadmap.
ScopePackaging only: no versioning, dependencies, structured or compiled format, validation or semantics. No skill IR or formal-verification tooling exists anywhere in the ecosystem, so this repo's format-2 + typed <leaf>.cue model + Z3 model tier has no incumbent and no visible competition.
AdoptionReal and cross-harness: SKILL.md is native in OpenAI Codex CLI, Gemini CLI, GitHub Copilot, VS Code, Cursor, ~40 products. A harness-neutral skill IR compiling down to SKILL.md rides this distribution instead of fighting it.
Skills Over MCPSEP-2640, AAIF working group: skills served as read-only MCP Resources under skill:// URIs, with a skill://index.json catalog for progressive disclosure. Early prototypes, yet the only live standards work on skill packaging semantics. Watch it: it shapes what an IR must serialize to (aaif.io/blog/skills-over-mcp).

What it means for smine

Decision

Standards cover transport (MCP, ACP) and packaging (SKILL.md). Execution semantics and evaluation have zero incumbent and zero incubation: exactly the layers built here (skill IR, Z3 semantics, skilleval). Build them, keep SKILL.md as the compile target, track SEP-2640.
