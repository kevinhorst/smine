Skill map

Which skill hands off to which: raw idea to landed commit. The nightly mining pipeline has its own page, Smining.

Hand-offs are the typed pipeline edges in each skill's <leaf>.cue; make skills-check checks both sides agree. These tables are the reader's view. Authoring: Skills, skill model.

Plan format

Plan-producing skills share context/rules/plan.md: section catalog and plan interface (template via plan-template:), stacked table cells, in-plan Q&A (OPEN decision rows, never popups), changelog, mode-invariant code and visual evidence.

Changes to existing features

  • fdesign covers post-implementation tweaks through full restructurings, migrations and consolidations. The plan classifies impact (behavior-preserving | behavioral | contract-touching | no-change); the user never pre-classifies.
  • Post-implementation loop: implementation → verification → fdesign (new plan in the feature folder) → fimplement → its commit skill.
  • overlap (optional, read-only, between steps 4 and 5) lists recent same-repo sessions (via peek-mcp) whose diffs or plans touch the plan's files: collisions show before implementation.

Composition

Skills and workflows pipe into each other through three harness-native primitives.

PrimitiveHow
Skill fronts workflowSKILL.md resolves intake; the session then calls the Workflow tool on a script in the skill's directory (investigate, smine, skillroutine-eval).
Workflow nests workflowworkflow({scriptPath}, args) runs another workflow inline, sharing budget and concurrency; one nesting level only. The pipe primitive.
Workflow runs skillAn agent() stage whose prompt invokes the Skill tool and follows it unattended.

Pipe doctrine

  • A pipe is a thin workflow script in the consumer skill's workflows/ dir: it nests A's workflow via workflow(), adapts A's structured return to B's input contract in pure JS, runs B via an agent stage.
  • Paths a pipe needs travel in args: workflow scripts have no filesystem or env access.
  • One nesting level: pipes are never piped; a longer chain is one pipe script calling its children sequentially.
Note

The nesting primitive is unoccupied: its first instance, skillroutine-parallel-eval, retired with the matrix eval framework. /skillroutine-eval and /skillroutine-ab run headless roots via go run ./cmd/skilleval.
