## Design notes

- **SKILL-SKILLROUTINECREATE-FORMAT-014**: the harness UI shows the argument-hint string verbatim — a concrete example helps,
  a bracketed name list does not; the leading free-text title names the chat and the initial branch instead of the skill name.
- **SKILL-SKILLROUTINECREATE-PROCESS-007…013**: role classification is the one format axis with no machine check — the
  skill-entries gate verifies tag shape, section order and clause legality, never that a tag matches the statement's
  semantics; the register rule is prose-only. The challenger spawn is the compensating control: a fresh-context adversary
  whose only job is to argue the opposite reading, mirroring railroad-review's refuter pattern at authoring granularity.
  Sonnet suffices — the probes are mechanical transforms, not repo judgment.
- **SKILL-SKILLROUTINECREATE-LAYER-001**: layers carry triggers, not mandates — every layer is permanent maintenance
  (atoms need sources and queries, workflows need gen freshness), so a skill opts in per layer when its trigger holds,
  never wholesale because the reference sibling has it.
- **Register sweep (3.3.0)**: definitional FORMAT/NAMING/PACKAGE entries were retagged def/rule rather than reworded
  imperative — force-imperative wording papers over misclassification, the exact failure mode the challenger pass exists
  to catch. PLAN-001 became a rule (its section is context-kind; a step there trips the Structure-tab flow-in-context
  analysis, a stop does not).
